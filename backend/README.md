# Backend API

Basic Node.js + Express REST API backend.

## Install

```bash
cd backend
npm install
```

## Run development

```bash
npm run dev
```

## Run production

```bash
npm start
```

## Test

Open browser:

- http://localhost:8080/api
- http://localhost:8080/api/health
- http://localhost:8080/api-docs (Swagger UI)

## Environment

Copy `.env.example` to `.env` if needed:

```
PORT=8080
NODE_ENV=development
```
